# Experimental linear scDeBussy v2

`scdebussy.align` is additive. The existing `scdebussy.tl.scDeBussy` algorithm is
unchanged and remains the recommended method pending scientific validation.
Importing v2 does not import Torch. Branching and automatic tuning are not part
of this release.

## Fit, project, and compare

```python
from scdebussy import align

# X must already be finite and processed; pseudotime must be in [0, 1].
# These are explicit example settings, not universal biological defaults.
result = align.fit(
    adata,
    patient_key="patient",
    pseudotime_key="s_local",
    n_landmarks=100,
    locality_radius=0.1,
    beta=1.0,
)
projection = align.project(result)
description = align.summarize(result, projection)

# One label per patient, rather than one independent observation per cell.
labels = adata.obs.groupby("patient")["condition"].first().to_dict()
comparison = align.compare(
    result, labels, scheme="exchangeable", seed=2026, n_perm=9999
)

# Only this explicit call writes to AnnData. Legacy keys are preserved.
result.write(adata)
adata.write_h5ad("aligned_with_v2.h5ad")
```

`fit` does not normalize expression, transform pseudotime to cell ranks, modify
AnnData, or use condition labels. Patient order follows first occurrence in
`obs`; gene order follows `var_names`. Cell and gene identifiers must be unique.
Public fitting requires at least two landmarks; the low-level lattice accepts
`1x1` solely to support analytic fixtures.

Supply both `eta_i` and `eta_d` to override automatic calibration. In the
default calibration, the 90th percentile of supported row-minimum mismatch
costs within a normalized-coordinate band of width `0.25` determines both
extension costs. Opening costs are `kappa_i*eta_i` and `kappa_d*eta_d`, with
both multipliers defaulting to `3`. Calibration is performed once against the
initial consensus. An empty or zero result raises `DegenerateCalibrationError`;
choose explicit positive extension costs instead of silently accepting free gaps.

`locality_radius` and `beta` are required. All resolved settings are retained in
`result.config`. The configuration in `scripts/v2/contract.json` is a named,
frozen **benchmark** preset and is not advertised as a general scientific default.

`project(result, new_adata)` supports new cells from already fitted patients.
It validates gene identities and order, and rejects unknown patients. Projection
uses pseudotime and the stored alignment; it does not refit or inspect expression
to infer a new patient's alignment.

## What the model computes

For patient landmarks `x[i,g]` and consensus `B[j,g]`,

```
Delta[i,j] = mean_g precision[i,g] * (x[i,g] - B[j,g])**2
q(path) = exp(-beta * energy(path)) / Z
energy(path) = sum(matched Delta) + affine gap costs
```

This is a Gibbs latent-path model, not a normalized generative observation
likelihood. Uniform base measure means one unit of measure per admissible path.
Temperature multiplies the entire energy. Scaling every energy by `c` and
temperature by `1/c` leaves the posterior unchanged.

The immutable `LatticeModel` compiles to a numeric directed acyclic graph.
Enumeration, reference inference, and Numba inference consume that same graph.
The optimized kernels contain no independent gap or terminal-mode rules.

Coordinates count consumed landmarks. Matches consume `(1,1)`, insertions
`(1,0)`, and deletions `(0,1)`. Switching into a gap state pays opening plus
extension, including `I` to `D` and `D` to `I`; continuing a run pays extension.

- **Global:** start at `(0,0)` and finish at `(T_p,T)`. All gap runs, including
  leading/trailing runs, pay normal affine costs. No endpoint match is required.
- **Open:** a single entry offset, a core starting and ending in matches, and a
  single exit offset. Offsets pay extension costs only. Arbitrary orderings of
  terminal unmatched material do not multiply posterior mass. The no-match
  alignment is one additional path with energy `T_p*eta_i + T*eta_d`.

`posterior.log_a` contains unconditional match-edge log marginals. `insertion`
and `deletion` are per-landmark probabilities. Their local conservation laws are
`sum_j A[i,j] + insertion[i] = 1` and
`sum_i A[i,j] + deletion[j] = 1`. Charged gap-run counts exclude open offsets.

The match-count distribution distinguishes `P(N_M=0)` from `E[N_M]`. MAP edges
exist only for diagnostics; downstream quantities use posterior marginals.
Entropy is `beta * E[energy] + log Z`.

## Local support, precision, and optimization

Landmark coordinates are `i/T_p`; consensus coordinates are `j/T`. These are
rank-grid coordinates, not biological time or data-derived cell quantiles.

The smoother uses Gaussian kernels truncated at `locality_radius`, with bandwidth
equal to half the radius. Local count and Kish effective sample size are computed
from raw nonnegative kernel weights. Both must reach `n_min` (default `5`) for a
landmark to be matchable. Unmatchable rows have no match transitions. Distant
cells cannot create coverage through a Gaussian tail or an expanded bandwidth.

Local linear regression uses chunked sufficient statistics, falling back to a
local constant estimate when the regression system is singular. Reported mean
variance is the nonnegative weighted residual second moment divided by ESS.
This is an approximation, not an exact variance under arbitrary heteroskedastic
or correlated observations. Precision is `1/(variance + epsilon)`.

Initialization averages supported patient estimates equally at each grid point.
Only initialization interpolates unsupported positions, with nearest-value
extension at endpoints. No support anywhere raises `InsufficientSupportError`.

During EM, all precision, support, temperature, and gap parameters remain fixed.
Each M-step minimizes the conditional squared-error objective using `S1/S0`.
Log-normalized accumulation prevents tiny but finite posterior support from
being mistaken for structural zero. A genuinely unsupported element retains its
previous value. No post-fit barycenter smoothing occurs.

Every iteration records the free energy before the M-step, after the conditional
M-step, and after the following E-step. Both inequalities are checked. Stop after
three consecutive relative improvements no larger than `1e-6`, or 200 iterations.
The final E-step always describes the returned barycenter, even on non-convergence.

`s0`, `s1`, and `log_s0` in a result are computed from its **final posterior**.
Away from a fixed point, their ratio is the next conditional minimizer, not
necessarily the returned barycenter. `converged` does not claim a global optimum.
`identified` uses finite log support; ordinary `s0` can underflow even when a
position is structurally identified. `weakly_identified` defaults to `S0 < 1e-3`.

## Projection and interpretation

For each cell, normalize its kernel weights over all patient landmarks and use
`P(j|cell) = sum_i kernel_normalized[cell,i] * A[i,j]`. The unmatched probability
is a separate array, never consensus category zero. Cells with no local landmark
are fully unprojected. Cells with unprojected probability greater than `0.5` are
marked `unsupported`.

Position is conditional on retained mass and always accompanies unprojected
probability and entropy. Structural zero retained mass gives an NA position.
Log retained mass is also available: a finite conditional position on numerical
underflow must never be presented without its approximately-one unprojected mass.

Conditional posterior means can reverse even when individual paths are monotone.
The API reports reversals and does not change the posterior means with isotonic
regression. No Viterbi estimate is substituted for an uncertain posterior.

`summarize` returns matchability-weighted trapezoidal rank displacement, matched
transition occupancy, projected-cell occupancy, coverage mass, and unweighted
alignment-conditioned expression residuals. Undefined shapes/residuals are NA,
not zero. A gene's expression residual is deliberately not the weighted objective
gradient.

**Limits of interpretation:**

- One-to-one matching requires gaps to represent many ordinary time warps.
  Gaps can therefore mean resampling as well as unmatched observations.
- Projected-cell occupancy combines biological abundance and the observation
  process. It cannot by itself distinguish abundance from censoring.
- Expression changes along a trajectory can be indistinguishable from time
  shifts. `nonidentifiable_pair()` gives identical observations with two such
  latent interpretations.
- Alignment entropy is conditional on the chosen energy, panel, support rules,
  and temperature. It is not a calibrated posterior over all biological models.

## Patient-level inference

Exactly two conditions and at least two eligible patients per group are needed.
The kinetic statistic is an absolute difference of patient means. Occupancy uses
Wasserstein-1 distance between equally weighted patient occupancy distributions,
with ground distance `abs(j/T - j'/T)`. Expression uses squared differences of
unweighted supported-patient residual means, integrated with weights proportional
to the smaller group's summed residual support.

Supply patient-ID mappings, or arrays explicitly ordered as `result.patients`:

- `scheme="exchangeable"`: unrestricted patient-label permutation.
- `scheme="blocked", blocks=...`: permutations within supplied blocks.
- `scheme="paired", pairs=...`: each pair must have exactly one patient per group.

The caller must justify exchangeability. Fitting remains fixed because it is
label-independent. Group support and expression weights are recomputed for every
permutation. Missing observed statistics or any undefined sampled null statistic
produce `not_testable`; null assignments are never silently dropped. No movable
labels also produces `not_testable`.

P-values use the plus-one formula with an explicit seed. BH correction is applied
within each family only; no cross-family correction or general guarantee under
arbitrary dependence is claimed. The kinetic and occupancy families each contain
one test for a two-group comparison; the expression family contains the genes.
These test **condition association with fitted quantities**, not an isolated
biological cause. A perturbation in one channel can change another fitted channel.
The validation report records such cross-channel responses and limited gene-level
power in the current preset; passing numerical suite thresholds is not proof of
a clean biological decomposition.

## Validation and computational cost

```bash
PYTHONPATH=src python -m pytest tests
PYTHONPATH=src python scripts/v2/validate.py --suite smoke --output validation/v2/smoke
PYTHONPATH=src python scripts/v2/validate.py --suite all --output validation/v2/full
PYTHONPATH=src python scripts/v2/summarize_validation.py validation/v2/full
PYTHONPATH=src python scripts/v2/real_data.py \
  --adata /path/to/the/nine_patient_preprocessed_input.h5ad \
  --config scripts/v2/real_data_config.json --output validation/v2/real_data.json
```

The benchmark contract freezes calibration/held-out seeds, null replicates,
presets, and numerical thresholds before execution. Runs are resumable; cached
cases must match the contract fingerprint. Smoke success is not scientific
acceptance. Failures and non-convergence remain in the reports.
The aggregation step reports condition-effect detection, kinetic displacement
against matched-noise calibration runs, gene recovery, and resolution stability.
These descriptive diagnostics do not introduce new acceptance thresholds after
seeing the held-out results.

Distance construction uses `O(T_p*T*G)` operations without a three-dimensional
distance tensor. Main inference is `O(T_p*T)` in time and memory. Exact match-count
distributions cost `O(T_p*T*min(T_p,T))` in time and memory and are computed only
for the final returned E-step. The graph topology cache holds at most eight
immutable templates. Cell projection costs `O(N*T_p*T)` and stores `O(N*T)` output.
Permutation tests cost `O(n_perm*P*T*G)`; the full validation suites are intentionally
larger than the unit tests.

See `validation/v2/README.md` for the recorded environment, test evidence,
scientific gate status, and baseline reproduction limitations. Replacement of
v1 requires Gates A–C, reproduction of the real baseline, and the real-data
coverage/purity criteria. No benchmark runner automatically recommends v2.
